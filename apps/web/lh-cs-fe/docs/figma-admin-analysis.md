# 🏗️ LH 어드민 페이지 구현 설계

## 📋 Figma 디자인 분석 결과

### 확인된 주요 컴포넌트들:

#### 1. **데이터 테이블 컴포넌트**

- PC 컨텐츠 목록 테이블
- 검색 및 필터 기능
- 페이지네이션
- 정렬 기능

#### 2. **상담 관리 대시보드**

- 실시간 상담 현황
- 상담사 할당 관리
- 상태별 필터링

#### 3. **모달 시스템**

- 각종 팝업 및 모달
- 폼 입력 모달
- 확인/취소 다이얼로그

#### 4. **상태 관리 컴포넌트**

- 상담 상태 표시
- 진행 상황 인디케이터
- 알림 배지

## 🛠️ 구현 계획 (기존 위젯 활용)

### ✅ 이미 구현된 위젯들

- **GNB Widget**: 상단 네비게이션 (사용자 정보, 알림, 메뉴 토글)
- **LNB Widget**: 좌측 네비게이션 (메뉴 구조, 접기/펼치기)
- **Profile Widget**: 사용자 프로필 (정보 표시, 액션 버튼)

### Phase 1: 어드민 레이아웃 통합

```
pages/admin/
├── layout.tsx          # GNB + LNB + 메인 컨텐츠 영역
├── dashboard/          # 대시보드 페이지
├── content/           # 컨텐츠 관리
├── consultation/      # 상담 관리
└── settings/          # 설정
```

### Phase 2: 데이터 테이블 & 대시보드 컴포넌트

```
features/
├── admin-dashboard/    # 대시보드 기능
│   ├── ui/            # 대시보드 UI 컴포넌트
│   ├── model/         # 대시보드 데이터 모델
│   └── api/           # 대시보드 API
├── data-table/        # 재사용 가능한 테이블

```

### Phase 3: 비즈니스 로직 & API 연동

```
shared/ui/
├── data-table/         # 테이블 컴포넌트
├── modal/              # 모달 시스템
├── status-badge/       # 상태 표시

```

### Phase 3: 비즈니스 로직

```
features/
├── content-management/ # 컨텐츠 관리 기능
├── consultation-management/  # 상담 관리 기능
└── user-management/    # 사용자 관리 기능
```
